# Password Strength Checker

A simple **frontend-only web app** to check password strength in real-time using **JavaScript**, with a modern **HTML + CSS + Bootstrap** UI.  

## Features
- Real-time password strength feedback (Weak / Moderate / Strong)
- Color-coded results for easy understanding
- Responsive and modern UI
- Fully frontend → no backend required

## Live Demo
Check it out here: [Live Demo](https://password-strength-checker-brown.vercel.app/)

## How to Use
1. Open the live demo link or run locally by opening `index.html` in a browser.
2. Enter your password in the input box.
3. Click **Check Strength** to see feedback.

## Tech Stack
- HTML5
- CSS3
- Bootstrap
- JavaScript
